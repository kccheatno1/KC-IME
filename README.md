# KC輸入法

現代化的 Windows 注音輸入法。

## 特色

- **可展開的候選窗**：選字時按 → 展開成格狀，一次看到更多候選字，數字鍵直接選字
- **15 套佈景主題**：深色、淺色、霓虹、櫻花、午夜、森林、抹茶……也能完全自訂顏色，調整時即時預覽
- **工作列圖示風格**：5 種形狀，可跟隨工作列深淺或佈景主題配色
- **快捷鍵自由設定**：點一下熱鍵框、直接按下組合鍵就完成，衝突即時提示
- **全新設定介面**：側欄分類＋搜尋框，所有設定一搜就到
- **特殊符號／快捷符號**：在模擬畫面與虛擬鍵盤上直接編輯
- **括號首選【】**：Shift+[ 預設輸出【】，按 ↓ 可改選『』〔〕《》等
- **安裝免重新開機**

## 下載

到 [Releases](../../releases/latest) 下載最新版：

| 檔案 | 說明 |
|---|---|
| `KC輸入法-Setup-<版本>.exe` | 一般使用者請下載這個 |
| `KC輸入法-<版本>.msi` | 企業／大量部署用 |

## 系統需求

- Windows 10 / 11（64 位元）
- 目前不支援 ARM 處理器的電腦

## 安裝

1. 執行 `KC輸入法-Setup-<版本>.exe`，按「安裝」。
2. 安裝完成後**不需要重新開機**。新開啟的程式就能使用 KC輸入法；已開啟的程式請關閉後重新開啟。
3. 已有的使用者詞庫會保留。

## 使用

- 切換中／英：按一下 Shift
- 展開候選窗：選字時按 →
- 開啟設定：在工作列「中／英」圖示上按右鍵 →「設定 KC輸入法」

## 解除安裝

「設定」→「應用程式」→ 找到「KC輸入法」→ 解除安裝。
